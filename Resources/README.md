# Resources

A curated collection of external resources for bioinformatics and Python-based data analysis: GitHub repositories, books, and websites.

## GitHub Repositories

- [Biopython](https://github.com/biopython/biopython) - Freely available tools for biological computation in Python, including parsers for common bioinformatics file formats and access to online services like NCBI.
- [Scanpy](https://github.com/scverse/scanpy) - Scalable Python toolkit for analyzing single-cell gene expression data (preprocessing, visualization, clustering, trajectory inference).
- [pysam](https://github.com/pysam-developers/pysam) - Python wrapper for samtools/htslib, for reading and manipulating SAM/BAM/VCF/BCF files.
- [pyfaidx](https://github.com/mdshw5/pyfaidx) - Pythonic, efficient random access to FASTA files without loading the whole file into memory.
- [SeqKit](https://github.com/shenwei356/seqkit) - Fast, cross-platform toolkit for FASTA/FASTQ file manipulation.
- [cnsplots](https://github.com/faridrashidi/cnsplots) - Gallery of Python plotting examples for computational and systems biology.
- [Awesome-Bioinformatics](https://github.com/danielecook/Awesome-Bioinformatics) - Large curated list of bioinformatics software, resources, and libraries across many languages and domains.

## Books

- [Bioinformatics Data Skills](https://www.oreilly.com/library/view/bioinformatics-data-skills/9781449367480/) - Vince Buffalo (O'Reilly). Covers reproducible, robust data analysis practices for genomics, including the Unix command line, Git, and Python/R basics.
- [Python for Data Analysis](https://wesmckinney.com/book/) - Wes McKinney (O'Reilly). Written by the creator of pandas; the standard reference for data wrangling with pandas and NumPy, directly applicable to the tabular data processing in this repo.
- [Practical Computing for Biologists](https://practicalcomputing.org/) - Steven H.D. Haddock & Casey W. Dunn. Introduces programming, scripting, and data handling skills for biologists with little or no computing background.

## Websites

- [Rosalind](https://rosalind.info/) - Learn bioinformatics and programming through a series of solvable problems, from basic Python to advanced algorithms.
- [Biostars](https://www.biostars.org/) - Q&A forum for bioinformatics, widely used for troubleshooting tools, workflows, and data formats.
- [NCBI](https://www.ncbi.nlm.nih.gov/) - National Center for Biotechnology Information; primary source for sequence databases (GenBank, SRA), BLAST, and reference genomes.
- [Galaxy Project](https://galaxyproject.org/) - Open, web-based platform for accessible, reproducible bioinformatics analysis and workflow management.
- [RNA-seqlopedia](http://rnaseq.uoregon.edu/) - Overview of RNA-seq experimental design and analysis choices, from library prep to differential expression.
